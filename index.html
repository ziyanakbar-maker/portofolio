Tentang Saya

Dedikasi Membangun Web yang Fungsional & Indah

Mengenal lebih dekat perjalanan saya di bidang rekayasa web, teknologi yang saya kuasai, dan nilai-nilai yang saya pegang.

Saya seorang Web Developer yang antusias terhadap clean code dan arsitektur responsif.

Perjalanan pemrograman saya berakar dari rasa ingin tahu yang mendalam tentang bagaimana sebuah antarmuka web dapat menghubungkan pengguna dengan kebutuhan mereka secara mulus. Saya menguasai fondasi HTML5 Semantik, styling modern dengan Bootstrap 5 dan Tailwind CSS, serta logika dinamis dengan JavaScript.

Setiap baris kode yang saya tulis mengutamakan kerapian tampilan, aksesibilitas (a11y), fleksibilitas di layar ponsel (≈ 375px), hingga kenyamanan browsing di layar desktop lebar.

Mobile-First Approach

Tampilan rapi tanpa overflow pada layar 375px hingga monitor ultra-wide.

HTML5 Semantik

Memanfaatkan tag header, nav, main, section, dan footer untuk SEO & aksesibilitas.

TokoKita - Platform E-Commerce Modern

Deskripsi Proyek

TokoKita adalah platform belanja online responsif yang dirancang untuk memberikan pengalaman bertransaksi tanpa hambatan bagi pengguna ponsel maupun komputer desktop.

Fitur Utama:

  • Katalog produk dinamis dengan sistem pencarian dan filter harga.
  • Keranjang belanja berbasis state JavaScript interaktif.
  • Validasi checkout form dengan pesan eror yang jelas.
  • Desain mobile-first yang nyaman dibuka pada ponsel lebar 375px.

TaskFlow - Manajemen Tugas & Kanban

Deskripsi Proyek

TaskFlow mempermudah pengelolaan sprint dan pengerjaan tugas proyek harian menggunakan papan Kanban interaktif yang fleksibel.

Fitur Utama:

  • Kolom fleksibel: To Do, In Progress, dan Done dengan counter otomatis.
  • Tag prioritas dengan warna kode indikator (High, Medium, Low).
  • Penyimpanan otomatis ke browser storage sehingga data tidak hilang saat refresh.
  • Antarmuka ramah sentuhan (touch-friendly) untuk perangkat mobile.
