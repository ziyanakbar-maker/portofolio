Latar Belakang & Perjalanan

Halo! Saya adalah seorang pengembang web yang memiliki antusiasme tinggi dalam membangun situs web interaktif dan adaptif. Ketertarikan saya dimulai dari rasa takjub melihat bagaimana beberapa baris kode HTML dan CSS dapat bertransformasi menjadi antarmuka visual yang memudahkan ribuan pengguna.

Dalam setiap proyek, saya memprioritaskan penerapan HTML5 Semantik agar dokumen terstruktur secara logis, mudah dibaca mesin pencari, dan aksesibel bagi seluruh pengguna. Dikombinasikan dengan framework modern seperti Bootstrap 5 dan Tailwind CSS, saya mampu menghasilkan desain yang konsisten, estetis, dan rapi pada beragam resolusi layar—mulai dari smartphone mungil (≈ 375px) hingga layar monitor desktop beresolusi tinggi.
